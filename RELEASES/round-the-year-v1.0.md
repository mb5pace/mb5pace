# Round the year — v1.0

First preserved release of the circular GitHub contribution calendar.

- Seven concentric weekday rings.
- One radial spoke per week.
- Each day is drawn as a curved annular-sector tile (outer arc + reversed inner arc).
- A clockwise sweep reveals the year.
- Contribution levels use a green intensity scale.
- Animated GIF for the GitHub profile README, plus a static PNG snapshot.

## Files

- `assets/round-the-year.gif` — looping animation.
- `assets/round-the-year-v1.0.png` — completed static snapshot.
- `scripts/generate-round-the-year.py` — generator.
- `data/github.json` — contribution data used for this snapshot.

This version is preserved on the `release/round-the-year-v1.0` branch.
